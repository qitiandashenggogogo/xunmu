## 一、定位与命名原则

本应用是一款专注于 **macOS 14+ 原生体验的文件名搜索工具**。它的核心技术与交互特质为：
1. **纯粹原生**：AppKit 原生表格、不扫正文、无多余 Web/Electron 包装。
2. **敏捷直达**：任意位置子串匹配，一两个汉字即出结果，无多余 Top-K 截断。
3. **状态持久与离线友好**：外置盘离线后索引依旧可查；应用内深入目录后，前进、后退保留原结果选区与滚动位置。
4. **克制私密**：文件名索引与查询在纯本机运行，当前本地诊断不联网，不收集或上传用户文件名与路径。

### 命名规避原则
* **不采用“Everything for Mac”或其生硬变体**：避免侵权隐患与山寨感，建立独立的产品格调。
* **不堆砌泛泛的同义词**：避免如“快搜、秒查、神寻、极速搜”等模板化工具名。
* **不以性能保证做命名理由**：当前百万条合成索引峰值 RSS 约 1175 MiB，内存并未改善，命名不宜做“超轻、零内存”等虚构承诺。
* **双语舒适**：中文名凝练（2字为主，符合 macOS 习惯），拉丁名拼写易读且易发音，GitHub 仓库 Slug 简短利落。

## 二、五组命名提案

### 方案一：寻目 · Xunmu

* **中文名**：寻目
* **拉丁名**：Xunmu（英文亦可副标展示为 *Lookfind*）
* **建议仓库 Slug**：`xunmu`（或 `xunmu-mac`）
* **含义与来源**：“目之所及，寻之有果；历历在目，见字知录”。强调搜索的目的不是看冗余信息，而是“让要找的目标文件重新出现在眼前”。
* **听感与气质**：平直、简净、收敛。发音平稳自然，气质贴近 macOS 原生内置实用工具（如「访达」「备忘录」「数码测色计」）。
* **为何适合本项目**：
  * 匹配 AppKit 原生极简界面的克制感，不张扬、不高调。
  * 强调“文件名一瞥即得”的纯视觉定位能力，不宣称正文语义等重型功能。
* **一句短介绍**：克制、静默而迅速的 macOS 原生文件名定位器。
* **潜在缺点**：整体风格偏向实用工具，作为独立开源产品可能略显“素雅”，在社区传播时缺乏戏剧化的技术极客感。
* **重名与占用情况**：尚未做该名称在 GitHub / Mac App Store / 全球商标注册中的深度占用核查，不承诺排他唯一性。仅初筛主流 macOS 文件检索器（Alfred, Raycast, EasyFind, Find Any File, ProFind, HoudahSpot）无同名。

### 方案二：留迹 · Vestige

* **中文名**：留迹
* **拉丁名**：Vestige（发音 /ˈvɛstɪdʒ/，或拼音 *Liuji*）
* **建议仓库 Slug**：`vestige-mac`（或 `vestige`）
* **含义与来源**：“盘离留迹，舟过有辙”。即使外置机械盘或移动 SSD 物理拔下，其元数据与目录层级依然如实留有印记；即便窗口切换或进入子目录，前一帧的搜索选区与滚动位依然完整留存。
* **听感与气质**：沉稳、具时间沉淀感与可靠感。拉丁名 *Vestige* 具典雅的学术与工程气质。
* **为何适合本项目**：
  * 精准击中本工具最显著的差异化护城河——**外置盘离线仍可检索**与**导航栈状态深度保留**。
  * 给予多盘工作者（摄影、剪辑、归档同事）极强的安全感。
* **一句短介绍**：即便硬盘离线，仍可按图索骥的 macOS 索引记忆工具。
* **潜在缺点**：“迹”字带有事后审计或取证（Forensics/Trace）色彩，个别初见用户可能会误以为是“文件变更审计器”或“版本历史恢复软件”。
* **重名与占用情况**：待查证。跨平台开源软件中偶见类似词根（未经官方出处深度核对），尚未做该名称在 GitHub / Mac App Store / 全球商标注册中的深度占用核查，不承诺排他唯一性。

### 方案三：探微 · Tanwei

* **中文名**：探微
* **拉丁名**：Tanwei（副标亦可作 *Subseek*）
* **建议仓库 Slug**：`tanwei`（或 `tanwei-mac`）
* **含义与来源**：“见微知著，一字探微”。取自古语“阐幽探微”。
* **听感与气质**：灵动、锐利、具东方书卷气。
* **为何适合本项目**：
  * 呼应本工具最具实用价值的搜索特性——**支持任意位置子串**与**一至两个汉字即刻命中**。
  * 不需要用户记住完整文件名，只要有一鳞半爪的“微小线索”，即可穿透已建立的索引直达目标。
* **一句短介绍**：仅凭一两字微小线索，直透已建索引的轻巧检索器。
* **潜在缺点**：汉字偏向文气，若面对纯英文或海外开源社区，“Tanwei”拼音的国际记忆度不如纯拉丁词直接。
* **重名与占用情况**：尚未做该名称在 GitHub / Mac App Store / 全球商标注册中的深度占用核查，不承诺排他唯一性。

### 方案四：卷录 · Volcat

* **中文名**：卷录
* **拉丁名**：Volcat（由 **Vol**ume + **Cat**alog 复合而成）
* **建议仓库 Slug**：`volcat`（或 `volcat-mac`）
* **含义与来源**：“卷（Volume）之图谱，录（Catalog）以载道”。其名直接对应本项目核心底层模型：`VolumeRecord`（卷身份）与 `CatalogStore`（持久目录）。
* **听感与气质**：干脆、现代、极具开源极客范。英文 *Volcat* 发音清脆（类似“沃卡特”），结构紧凑利落。
* **为何适合本项目**：
  * 直面多盘同事最头疼的“盘库 / 找东西在哪个盘”的痛点。把内外置介质当成一个个清晰的“卷”，并为之编目立卷。
  * 程序员与技术用户接受度极高，代码架构与品牌意象完全契合。
  * 商业感适中，既可作为精巧的个人开源项目，也具备长期演进的独立工具品牌相。
* **一句短介绍**：专为内外置卷介质编目提速的 macOS 原生目录检索工具。
* **潜在缺点**：“卷”字在当下中文语境中易引起“内卷”的联想；此外该名字强调了“目录与分卷”，速度感的隐喻稍弱于即时搜索类名称。
* **重名与占用情况（重要核对）**：
  * **已知跨领域同名项目**：经公开核实，气象与火山遥感领域存在知名科学计算软件包使用完全相同的缩写与名称——美国国家海洋和大气管理局（NOAA）官方与威斯康星大学空间科学与工程中心（SSEC）的 **VOLCAT**（VOLcanic Cloud Analysis Toolkit）。
    * 出处：NOAA 报道（https://www.nesdis.noaa.gov/news/popocatepetl-volcano-erupts-mexico ）、项目主页（https://volcano.ssec.wisc.edu/ ）与 Git 仓库（https://gitlab.ssec.wisc.edu/volcat ）。
    * 已确认的事实：该项目属于大气遥感科学领域，名称已被科学软件采用，**绝非全球独创**。本提案未评估商标或法律混淆风险，不能由领域不同推出没有冲突。
  * 尚未做该名称在 Mac App Store、跨国软件商标分类（第9类/第42类）的深度注册检索，不承诺排他唯一性。

### 方案五：悉寻 · Xixun

* **中文名**：悉寻
* **拉丁名**：Xixun（副标亦可作 *Allmark*）
* **建议仓库 Slug**：`xixun`（或 `xixun-mac`）
* **含义与来源**：“悉数归拢，尽在所寻”。作为产品愿景隐喻，脱胎自“Everything”的内核追求，用内敛的东方语言重新表达。
  * **重要事实边界**：本产品“悉寻”是设计愿景，**并不承诺无遗漏**。搜索仅覆盖用户已显式添加且已完整建立的本地索引范围；受权限限制的目录、离线卷中的过期未校验数据、以及中断未完成的扫描，均存在无法检索或需重新校验的情况。
* **听感与气质**：清朗、轻盈、收敛自如。双音节皆为轻擦音（xī xún），读来毫无沉重感。
* **为何适合本项目**：
  * 不照抄 Windows 的 "Everything" 叫法，却在品牌意象上呼应“多盘已建索引范围尽数可查”的愿景。
  * 音律优美，界面标题栏排版极简耐看。
* **一句短介绍**：覆盖已建索引范围的 macOS 轻型文件名搜索器。
* **潜在缺点**：“悉”字在部分输入法中非第一候选字（常见候选为西、息、吸），口头向同事安利时往往需要解释“熟悉/悉知的悉”。
* **重名与占用情况**：尚未做该名称在 GitHub / Mac App Store / 全球商标注册中的深度占用核查，不承诺排他唯一性。

## 四、推荐历程与最终定案

* **模型原推荐**：方案四「卷录 · Volcat」（极客/多盘工程感）。
* **用户最终定案**：**方案一「寻目 · Xunmu」**（原生系统工具风）。  
  用户认可其质朴克制、完全契合 macOS 原生人机工程习惯的特点。
  配套应用图标已选定**图标 A（文件夹＋放大镜，蓝青配色）**，由纯 Swift 代码通过 CoreGraphics 矢量生成。

## 五、局限性与待查证项声明

1. **未做全球商标与排他性检索**：上述初筛仅针对已知主流 macOS 效率工具、GitHub 热门开源仓库及常见软件。**未进行中国商标网、USPTO 及国际类目（第9类、第42类）的深度商标冲突排查**，无法承诺法律层面的排他唯一性。
2. **跨领域同名真实存在**：方案四 `Volcat` 已被气象与火山遥感软件（NOAA/SSEC VOLCAT）正式使用（出处见方案四详述）；方案二 `Vestige` 在其他技术领域亦偶有出现。不声称任何方案“全球绝无同名”。
3. **Slug 最终占用待实测**：建议的 GitHub Slug（如 `volcat`、`xunmu`）在实际创建仓库前需在目标 GitHub 组织或个人账户下确认是否被占用或保留。
4. **最终决定权**：本提案仅为创意与产品层面的收敛分析，最终命名由用户在方案对比后正式定夺。
